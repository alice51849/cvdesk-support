ATS resume checklist 2026

An applicant tracking system (ATS) has to read your resume before a recruiter can search it, rank it or open it. Most “ATS rejections” are really parsing problems — a name stuck in a page header, a two-column layout read out of order, a skill written in words the job post never uses. Run the 25 checks below on every resume you send. They take about ten minutes and they do not depend on any particular tool.

What an ATS actually does with your file

When you upload a resume, the system converts it to plain text, splits that text into fields (contact details, job titles, employers, dates, education, skills) and stores those fields in a candidate profile. Recruiters then search and filter that profile, often by keywords and by answers to screening questions. Two things follow from this:

  • If the text cannot be extracted cleanly, the profile is wrong. A recruiter searching for “Python” will not find you if your skills sat inside an image or a text box the parser skipped.
  • If the words do not match, the search does not match. Many systems are simple keyword search behind the scenes. “Client management” and “account management” may not be treated as the same thing.

So the checklist is split into two halves: can the machine read it, and does it say what the job asks for.

Checks 1–6: file and format

  1. Use the format the posting asks for. If it says .docx, send .docx. If it accepts PDF, a text-based PDF is fine for most modern systems.
  2. Make sure the PDF has real, selectable text. Open it, press select-all and copy. Paste into a plain text editor. If nothing pastes, or the order is scrambled, the ATS will see the same mess.
  3. One column. Two-column designs are often read left-to-right across both columns, mixing your skills into your job history. Put everything in a single top-to-bottom column.
  4. No tables, text boxes or shapes for important content. Some parsers skip them entirely. Use plain paragraphs and simple bullet points instead.
  5. Nothing important in the page header or footer. Name, email and phone belong in the body of page one, not in Word’s header area.
  6. Standard fonts, normal size. A common sans-serif or serif face at 10–12 pt. Avoid icons in place of words (a phone glyph instead of the word “Phone” is fine for humans, invisible to some parsers).

Checks 7–11: headings and structure

  1. Use standard section headings. “Experience” or “Work Experience”, “Education”, “Skills”, “Certifications”, “Projects”. Creative labels like “Where I’ve Made an Impact” can confuse field mapping.
  2. Job entries in a consistent order. Job title, employer, location, dates — the same order for every role.
  3. Consistent date format. Pick one and use it everywhere: “Mar 2023 – Aug 2025” or “03/2023 – 08/2025”. Write “Present” for a current role. Avoid seasons (“Summer 2024”) and bare years where months are known.
  4. Contact block on one or two plain lines. Full name, city and state (or city and country), phone, email, LinkedIn URL. No street address is needed.
  5. Reverse-chronological order inside Experience and Education, most recent first.

Checks 12–18: keywords that match the job description

  1. Copy the job description into a note and highlight every hard skill, tool, certification and job-title phrase.
  2. Mirror the exact wording where it is true. If the post says “stakeholder management” and you did it, use that phrase, not a synonym only.
  3. Write acronyms both ways once: “Search Engine Optimization (SEO)”, “Certified Public Accountant (CPA)”.
  4. Put the target job title near the top, in your summary line, if it honestly describes you.
  5. Show keywords in context, not only in a list. “Reduced month-end close from 8 to 5 days using NetSuite saved searches” beats a bare “NetSuite”.
  6. Do not paste the job description in white text or stuff keywords. Recruiters see the parsed text, and it reads badly.
  7. Match the must-haves first. If the post lists a required license or degree, make sure it appears in plain words in Education or Certifications.

Checks 19–25: content a human will read next

  1. Each bullet starts with a verb and, where possible, ends with a result or a number.
  2. Three to six bullets per recent role; fewer for older ones.
  3. One to two pages for most applicants in the US.
  4. No photo, age, marital status or date of birth on a US resume.
  5. File name that a recruiter can find later: Firstname-Lastname-Resume-Role.pdf.
  6. Spell-check, then read it once aloud.
  7. Re-check the plain-text paste test after every edit to layout.

Copy-ready checklist

Before every application

  • ☐ Format matches posting (PDF with selectable text, or .docx)
  • ☐ Single column, no tables / text boxes / graphics for content
  • ☐ Name and contact details in the body, not the header
  • ☐ Headings: Summary · Experience · Education · Skills · Certifications
  • ☐ Dates: one format everywhere, “Present” for current role
  • ☐ Top 10 keywords from the job post appear, in context, where true
  • ☐ Acronyms spelled out once
  • ☐ Required degree / license visible in plain text
  • ☐ No photo or personal data (US)
  • ☐ Plain-text paste test passed

Frequently asked questions

Is a PDF or Word file safer for ATS?

Follow the posting first. When both are accepted, a text-based PDF and a simple .docx are both widely read. The risk is not the extension but the layout inside it: scanned images, columns and text boxes.

Can an ATS read a two-column resume?

Some can, some cannot, and you rarely know which system an employer uses. A single column removes that uncertainty.

Does an ATS score guarantee I will pass?

No. Any score — including CV Desk’s — is an estimate. Employers set their own filters, knock-out questions and recruiter workflows.

How many keywords should I add?

There is no magic number. Cover the required skills and tools listed in the post, each in a real sentence about your work, and stop there.

No checklist, template or score can promise that a resume passes a particular employer’s applicant tracking system. Every employer configures its own system and its own screening questions.
